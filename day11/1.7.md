# step06.py 예제

지금 예제는 day10/openai/step7.py을 LangChain으로 변환한 것입니다.

step06.py의 핵심 주제는 "시스템 프롬프트(System Prompt)를 통한 페르소나 부여"입니다. 단순히 대화를 기억하는 것을 넘어, AI에게 특정한 역할(금융 전문가)과 답변 스타일을 지정하는 방법을 배웁니다.

---

## 1. 기반 지식 (Core Concepts)

### 1. 시스템 프롬프트 (System Prompt)

* LLM에게 대화 시작 전 부여하는 근본적인 지침입니다.
* AI의 역할(Persona), 말투, 답변 제약 사항, 전문성 수준 등을 설정합니다.
* 사용자는 이 메시지를 볼 수 없지만, AI의 모든 답변은 이 지침에 영향을 받습니다.

### 2. LangChain의 SystemMessage

* 메시지 리스트의 가장 첫 번째에 위치하는 것이 일반적입니다.
* HumanMessage(사용자), AIMessage(AI 답변)와 구분되어 시스템 차원의 명령을 전달합니다.

---

## 2. 주요 함수 및 클래스 사용법

### 1. SystemMessage 클래스

AI에게 정체성을 부여할 때 사용합니다.

```python
from langchain_core.messages import SystemMessage
from langchain_core.messages import SystemMessage

messages = [
    SystemMessage(content="너는 친절한 금융 전문 AI 비서이다."),
    # 이후에 과거 대화와 현재 질문이 이어짐
]

```

---

## 3. 코드 로직 분석 (메시지 구성 순서)

이 파일에서 가장 중요한 것은 messages 리스트를 만드는 순서입니다.

1. 1순위 (System): SystemMessage를 가장 먼저 넣어 AI의 기초 인격을 형성합니다.
2. 2순위 (History): 제한된 개수(MAX_HISTORY)만큼의 과거 대화 내역을 순서대로 넣습니다.
3. 3순위 (Current): 사용자가 방금 입력한 질문(HumanMessage)을 마지막에 배치합니다.

---

## 4. 학습 포인트

* 일관된 답변 유지: 시스템 프롬프트가 있을 때와 없을 때 답변의 톤(전문성, 친절함 등)이 어떻게 다른지 비교해 보세요.
* 구조적 데이터 핸들링: 라이브러리 버전에 따라 history의 데이터 형태가 바뀔 수 있으므로, print(history)를 통해 데이터 구조를 먼저 확인하는 습관을 익힙니다.
* 우선순위의 원리: 모델은 메시지 리스트의 순서대로 문맥을 파악한다는 점을 이해하는 것이 핵심입니다.
