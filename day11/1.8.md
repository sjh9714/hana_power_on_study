# step07.py 예제

step07.py의 핵심 주제는 "프롬프트 템플릿(Prompt Template)과 플레이스홀더(Placeholder)"입니다. 이전 단계까지 메시지 리스트를 코드로 직접 조작(append)했다면, 이제는 선언적인 구조를 만들어 체계적으로 프롬프트를 관리하는 방법을 배웁니다.

---

## 1. 기반 지식 (Core Concepts)

### 1. ChatPromptTemplate

* 기존에는 [SystemMessage(...), HumanMessage(...)]와 같이 파이썬 리스트를 직접 만들었습니다.
* ChatPromptTemplate을 사용하면 프롬프트의 구조(시스템 설정, 대화 위치, 질문 위치)를 미리 설계도처럼 정의해두고, 나중에 데이터만 채워 넣을 수 있습니다.
* 코드의 가독성이 좋아지고 프롬프트 수정이 매우 쉬워집니다.

### 2. MessagesPlaceholder

* 프롬프트 중간에 "여기에 대화 내역이 들어올 자리야"라고 표시해두는 예약석 같은 개념입니다.
* 단순한 문자열 변수가 아니라, 메시지 객체들의 리스트가 통째로 들어갈 자리를 지정할 때 사용합니다.

---

## 2. 주요 함수 및 클래스 사용법

### 1. ChatPromptTemplate.from_messages() 메소드 

역할별 메시지 템플릿을 정의합니다. 튜플 형태 ("역할", "내용")로 작성할 수 있어 직관적입니다.

```python
prompt = ChatPromptTemplate.from_messages([
    ("system", "너는 금융 전문가야."),
    MessagesPlaceholder(variable_name="chat_history"), # 대화 내역 자리
    ("human", "{question}") # 사용자 질문 자리 (중괄호는 변수)
])
```

### 2. MessagesPlaceholder(variable_name="이름")

* variable_name: 나중에 데이터를 채워 넣을 때 사용할 key 값입니다. 이 자리에 HumanMessage, AIMessage의 리스트가 삽입됩니다.

### 3. prompt.format_messages()

정의된 템플릿에 실제 데이터를 주입하여 최종적인 메시지 객체 리스트를 생성합니다.

```python

messages = prompt.format_messages(
    chat_history=chat_history_list, # 리스트 전달
    question=message                # 문자열 전달

)
```

## 3. 코드 로직 분석

이 파일은 프롬프트 구성을 정적 정의와 동적 실행으로 분리했습니다.

1. 정적 정의 (파일 상단): ChatPromptTemplate을 사용하여 챗봇의 정체성(System), 대화 이력 위치(Placeholder), 현재 질문 형식(Human)을 미리 정의합니다.
2. 동적 실행 (chat 함수 내):
    * Gradio의 history를 LangChain 메시지 리스트(chat_history)로 바꿉니다.
    * prompt.format_messages를 호출하여 템플릿의 {question} 자리와 chat_history 자리에 실제 값을 끼워 넣습니다.
    * 그 결과물(messages)을 모델에게 전달합니다.
