# step10.py 예제

step10.py의 핵심 주제는 "사용자 인터페이스(UI)를 통한 동적 모델 선택"입니다. 이전 단계까지는 개발자가 코드에서 직접 모델을 지정했다면, 이제는 사용자가 웹 화면에서 직접 원하는 AI(GPT 또는 Gemini)를 골라 대화할 수 있는 실전적인 구조를 구현합니다.

---

## 1. 기반 지식 (Core Concepts)

### 1. UI 데이터 바인딩 (Additional Inputs)

* Gradio의 ChatInterface는 기본적으로 message와 history 두 가지 인자만 함수에 전달합니다.
* 하지만 모델 선택 상자, Temperature 조절 바 등 추가적인 입력값을 서버로 보내야 할 때 additional_inputs 기능을 사용합니다.

### 2. 런타임 모델 초기화 (On-demand Initialization)

* 전역 변수로 llm을 하나만 만들어두는 대신, 사용자가 질문을 던질 때마다(chat 함수가 실행될 때마다) 선택된 모델에 맞춰 LLM 객체를 생성합니다.
* 이를 통해 하나의 채팅방에서 모델을 수시로 바꿔가며 성능을 비교해볼 수 있습니다.

### 3. 설정의 데이터화 (Configuration Mapping)

* "GPT-4.1 Mini"라는 UI 이름과 실제 모델 명칭(gpt-4.1-mini), 공급자(openai)를 딕셔너리(MODEL_CONFIG)로 매핑하여 코드를 깔끔하게 관리합니다.

---

## 2. 주요 함수 및 클래스 사용법

### 1. MODEL_CONFIG (딕셔너리 설계)

사용자에게 보여줄 이름과 실제 내부 설정을 분리하여 관리합니다.

```python

MODEL_CONFIG = {
    "GPT-4.1 Mini": {"provider": "openai", "model": "gpt-4.1-mini"},
    "Gemini 2.5 Flash": {"provider": "gemini", "model": "gemini-2.5-flash"}
}
```

### 2. gr.Dropdown()

사용자가 여러 옵션 중 하나를 선택할 수 있게 하는 UI 컴포넌트입니다.

```python
model_dropdown = gr.Dropdown(
    choices=list(MODEL_CONFIG.keys()), # ['GPT-4.1 Mini', 'Gemini 2.5 Flash']
    value="GPT-4.1 Mini",              # 기본값
    label="모델 선택"
)
```

### 3. chat(message, history, selected_model)

* selected_model이라는 세 번째 인자가 추가되었습니다. 이는 사용자가 드롭다운에서 선택한 값이 들어옵니다.
* 함수 내부에서 llm = get_llm(selected_model)을 호출하여 즉석에서 모델 객체를 만듭니다.

### 4. gr.ChatInterface(..., additional_inputs=[...])

UI 컴포넌트를 채팅 인터페이스에 결합합니다.

```python
demo = gr.ChatInterface(
    fn=chat,
    additional_inputs=[model_dropdown], # 여기에 리스트로 넣으면 chat 함수의 인자로 순서대로 전달됨
    ...
)
```

---

## 3. 코드 로직 분석 (흐름도)

1. UI 렌더링: 사용자의 브라우저에 채팅창과 모델 선택 드롭다운이 나타납니다.
2. 사용자 입력: 사용자가 모델을 고르고 질문을 입력한 뒤 전송합니다.
3. 데이터 전달: Gradio는 [메시지, 대화이력, 선택된 모델명]을 서버의 chat 함수로 보냅니다.
4. 모델 생성: 서버는 전달받은 모델명을 MODEL_CONFIG에서 찾아 OpenAI 또는 Gemini 객체를 생성합니다.
5. 응답 생성: 선택된 모델을 사용하여 답변을 생성하고 실시간으로 스트리밍합니다.

---

## 4. 학습 포인트

* 동적 프로그래밍: 입력값에 따라 프로그램의 동작(사용할 모델)이 실시간으로 바뀌는 구조를 이해하세요.
* Gradio 확장성: ChatInterface에 기본 기능 외에 커스텀 입력(드롭다운, 슬라이더 등)을 추가하는 방법을 익힙니다.
* 유지보수성: 새로운 모델(예: Claude)이 추가되어도 MODEL_CONFIG에 데이터만 추가하면 코드를 거의 건드리지 않고 확장할 수 있다는 점이 핵심입니다.

정리: step10은 기술적인 LangChain 활용을 넘어, 사용자 경험(UX)을 고려한 애플리케이션 구조를 만드는
단계입니다. 모델 간의 답변 차이를 한 화면에서 테스트하기에 매우 유용한 구조입니다.
