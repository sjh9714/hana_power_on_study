# LangChain 이란?

**랭체인(LangChain)** 은 LLM(대규모 언어 모델)을 이용한 애플리케이션을 쉽게 개발할 수 있도록 만들어진 프레임워크입니다.

대표적으로 다음과 같은 작업을 구현할 때 사용합니다.

* ChatGPT와 같은 챗봇
* RAG(Retrieval-Augmented Generation) 시스템
* 문서 검색 및 질의응답
* AI Agent
* 데이터베이스 질의
* PDF 분석
* 기업 내부 문서 검색 시스템

대표 프로젝트는 LangChain 입니다.

---

# 왜 필요한가?

LLM만 사용하는 경우

```python
from openai import OpenAI

response = client.chat.completions.create(
    model="gpt-5",
    messages=[
        {"role":"user","content":"안녕하세요"}
    ]
)
```

여기서는 단순히 질문 → 답변만 가능합니다.

하지만 실제 서비스는 다음이 필요합니다.

```text
사용자 질문
      ↓
문서 검색
      ↓
관련 정보 추출
      ↓
LLM 호출
      ↓
답변 생성
```

이 과정을 연결(Chain)해 주는 것이 LangChain입니다.

---

# LangChain의 핵심 구성요소

## 1. LLM

GPT, Claude, Gemini 같은 모델을 동일한 방법으로 호출할 수 있습니다.

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI()
```

---

## 2. Prompt Template

프롬프트를 템플릿화

```python
from langchain.prompts import PromptTemplate

prompt = PromptTemplate(
    input_variables=["name"],
    template="{name}에 대해 설명해줘"
)
```

결과

```text
홍길동에 대해 설명해줘
```

---

## 3. Chain

여러 작업 연결

```text
입력
 ↓
Prompt
 ↓
LLM
 ↓
출력
```

예시

```python
chain = prompt | llm
result = chain.invoke({"name":"Docker"})
```

---

## 4. Retriever

문서 검색

```text
질문
 ↓
벡터DB 검색
 ↓
관련 문서 추출
 ↓
LLM
```

RAG에서 가장 중요한 부분입니다.

---

## 5. Vector DB

문서를 임베딩하여 저장

대표 제품

* FAISS
* Chroma
* Milvus
* Weaviate
* Pinecone

---

## 6. Memory

대화 기억

```text
사용자 : 내 이름은 홍길동
AI : 기억했습니다.

사용자 : 내 이름이 뭐야?
AI : 홍길동입니다.
```

---

## 7. Agent

LLM이 도구를 선택하여 작업 수행

예시

```text
사용자:
오늘 서울 날씨 알려줘

Agent:
1. 날씨 API 호출
2. 결과 분석
3. 답변 생성
```

---

# LangChain + RAG 구조

```text
PDF
 ↓
문서 분할
 ↓
Embedding
 ↓
Vector DB 저장
 ↓
사용자 질문
 ↓
유사 문서 검색
 ↓
LLM
 ↓
답변 생성
```

예를 들어 투자설명서 PDF를 대상으로 한다면,

```text
투자설명서 PDF
 ↓
LangChain
 ↓
Chroma DB
 ↓
OpenAI Embedding
 ↓
GPT
```

를 구성하여

* 상품 설명 검색
* 수수료 조회
* 위험도 분석
* 투자 조건 질의응답

서비스를 만들 수 있습니다.

---

# LangChain과 LLM의 관계

비유하면:

```text
LLM = 엔진

LangChain = 자동차 프레임
```

* GPT, Claude, Gemini → 엔진 변경 가능
* LangChain → 엔진을 이용해 실제 서비스를 만드는 프레임워크

따라서 **RAG, AI Agent, 기업용 문서검색 시스템을 만들고 싶다면 LangChain은 가장 먼저 익혀야 하는 핵심 도구 중 하나**입니다.
