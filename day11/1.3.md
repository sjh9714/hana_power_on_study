# step02.py 예제

지금 예제는 day10/openai/step3.py을 LangChain으로 변환한 것입니다.

## 1. 기반 지식 (Core Concepts)

### 1. LangChain의 메시지 객체 (Message Objects)

LangChain은 LLM과 대화할 때 단순한 문자열이 아닌 역할(Role)이 부여된 객체를 사용합니다.
  
* HumanMessage: 사용자가 보내는 메시지입니다.
* AIMessage: AI(모델)가 응답하는 메시지입니다.
* SystemMessage: AI에게 "너는 전문가야"와 같은 페르소나를 부여하는 메시지입니다.

### 2. llm.invoke(messages)
  
생성된 모델 객체에 메시지 리스트를 전달하여 실행하는 함수입니다.

* 입력: [HumanMessage(content="안녕")] 형태의 리스트
* 출력: AIMessage 객체 (응답 텍스트는 .content 속성으로 접근)

### 3. 코드 실행 흐름 요약

1. 초기화: ChatOpenAI를 통해 GPT 모델과의 연결 통로를 만듭니다.
2. 입력 처리: 사용자가 채팅창에 메시지를 입력하면 Gradio가 chat 함수를 호출합니다.
3. 메시지 변환: 사용자의 텍스트(String)를 LangChain이 이해하는 HumanMessage 객체로 감쌉니다.
4. 모델 호출: llm.invoke를 통해 GPT에게 메시지를 전달하고 답변을 받습니다.
5. 출력: 답변 객체에서 텍스트(content)만 뽑아내어 사용자에게 보여줍니다.
