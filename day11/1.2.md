# LangChain을 사용하여 챗봇 구축 단계

LangChain은 LLM(OpenAI, Gemini, Claude 등)을 기반으로 **대화 관리, 프롬프트 관리, 메모리 관리, 문서 검색(RAG), Agent 기능**을 쉽게 구현할 수 있도록 도와주는 프레임워크입니다.

비전공자 기준으로 챗봇 구축 과정을 단계별로 설명하면 다음과 같습니다.

---

# 3단계 : PromptTemplate 적용

프롬프트를 재사용 가능하게 관리합니다.

>파일명 : step01-1.py

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4.1-mini",
    temperature=0.7
)

prompt = ChatPromptTemplate.from_template(
    """
    당신은 금융 전문가입니다.

    질문:
    {question}
    """
)

chain = prompt | llm

result = chain.invoke({
    "question": "예금과 적금의 차이점"
})

print(result.content)
```

# 4단계 : 대화 기능 추가

기본 챗봇 구현

>파일명 : step01-02.py


```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4.1-mini",
    temperature=0.7
)

while True:

    question = input("사용자 : ")

    if question == "exit":
        break

    response = llm.invoke(question)

    print("AI :", response.content)
```

# 5단계 : Message History 추가

대화 내용을 기억하도록 구현

```python
from langchain_core.messages import (
    HumanMessage,
    AIMessage
)

history = []

while True:

    question = input("사용자 : ")

    history.append(
        HumanMessage(content=question)
    )

    response = llm.invoke(history)

    history.append(
        AIMessage(content=response.content)
    )

    print(response.content)
```

# 8단계 : 문서 기반 챗봇(RAG)

실무에서 가장 많이 사용하는 단계입니다.

---

## PDF 읽기

```python
from langchain_community.document_loaders import PyPDFLoader

loader = PyPDFLoader("manual.pdf")

docs = loader.load()
```

---

## 문서 분할

```python
from langchain.text_splitter import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200
)

chunks = splitter.split_documents(docs)
```

---

## 임베딩 생성

```python
from langchain_openai import OpenAIEmbeddings

embedding = OpenAIEmbeddings()
```

---

## ChromaDB 저장

```python
from langchain_chroma import Chroma

vectordb = Chroma.from_documents(
    documents=chunks,
    embedding=embedding,
    persist_directory="./db"
)
```

---

# 9단계 : 검색 기능 구현

```python
retriever = vectordb.as_retriever()

docs = retriever.invoke(
    "투자 위험성"
)

print(docs)
```

---

# 10단계 : RAG 챗봇 완성

검색 + LLM 결합

```python
question = "투자 위험성은?"

docs = retriever.invoke(question)

context = "\n".join(
    [doc.page_content for doc in docs]
)

prompt = f"""
다음 문서를 참고하여 답변하세요.

{context}

질문:
{question}
"""

response = llm.invoke(prompt)

print(response.content)
```

# 11단계 : Agent 추가

LLM이 도구를 사용하게 함

예)

* 계산기
* 웹 검색
* DB 조회
* API 호출

```text
사용자
↓
Agent
↓
도구 선택
↓
실행
↓
결과 반환
```

예)

```text
"서울 날씨 알려줘"

→ 날씨 API 호출

"3*999 계산해줘"

→ 계산기 호출
```
