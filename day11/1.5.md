# step04.py 예제

지금 예제는 day10/openai/step5.py을 LangChain으로 변환한 것입니다.

step04.py의 핵심 주제는 "대화 문맥 유지(Multi-turn Conversation)"입니다. 이전 단계까지는 챗봇이 바로 전 질문만 기억했다면, 이제는 과거의 대화 내역을 모두 모아 GPT에게 전달함으로써 흐름이 이어지는 대화를 가능하게 합니다.

---

## 1. 기반 지식 (Core Concepts)

### 1. 대화의 문맥(Context) 이해

* LLM은 기본적으로 상태가 없는(Stateless) 모델입니다. 즉, 방금 한 질문도 다음 질문을 할 때는 잊어버립니다.
* 연속된 대화를 하려면 [과거 질문 + 과거 답변 + 현재 질문]을 통째로 모델에게 다시 보내야 합니다.

### 2. LangChain의 메시지 역할 확장

* HumanMessage: 사용자가 보낸 메시지.
* AIMessage: 모델이 보낸 응답 메시지. (이전 단계에서는 response.content만 썼지만, 이제는 이를 AIMessage 객체로 관리해야 합니다.)

---

## 2. 주요 함수 및 클래스 사용법

### 1. AIMessage 클래스

과거에 AI가 답변했던 내용을 LangChain 객체로 만들 때 사용합니다.

```python
from langchain_core.messages import AIMessage

#...

ai_msg = AIMessage(content="지난 대화 답변 내용")

```

## 3. 학습 포인트

* 무상태성 극복: 모델 자체는 기억력이 없지만, 개발자가 과거 내역을 다시 보내줌으로써 "기억력"을 구현한다는 원리로 이해하면 됩니다.
* 데이터 변환: 서로 다른 라이브러리(Gradio와 LangChain) 간에 대화 데이터를 어떻게 주고받는지(Mapping) 익히는 것이 중요합니다.
* 토큰 관리: 대화가 길어질수록 전달되는 메시지 양이 많아져 비용과 속도에 영향을 줄 수 있다는 점을 인지하기 시작하는 단계입니다. (이후 단계에서 이를 관리하는 법을 배울 수 있습니다.)
