## 1. 기반 지식 (Core Concepts)

### 1. 스트리밍(Streaming)이란?

* 일반 방식 (Invoke): 모델이 전체 답변을 다 만들 때까지 기다렸다가 한꺼번에 결과를 받습니다. 답변이 길면 사용자는 지루함을 느낄 수 있습니다.

* 스트리밍 방식 (Stream): 모델이 토큰(글자 단위)을 생성하는 즉시 클라이언트에 전달합니다. 챗GPT 웹사이트처럼 글자가 타이핑되듯 나타나는 효과를 줍니다.

### 2. 제너레이터(Generator)와 yield

* 파이썬에서 return은 함수를 종료하고 하나의 값을 반환하지만, yield는 값을 외부로 전달하면서도 함수의 상태를 유지합니다.
* yield를 사용하면 함수는 여러 번에 걸쳐 값을 내보낼 수 있으며, Gradio는 이 yield되는 값들을 실시간으로 받아 화면을 갱신합니다.

파이썬의 **제너레이터(Generator)** 와 **yield** 는 메모리를 효율적으로 사용하면서 데이터를 하나씩 생성할 수 있게 해주는 매우 중요한 기능입니다.

특히 AI, 데이터 처리, LangChain, FastAPI Streaming, LLM 응답 스트리밍 등에서 자주 사용됩니다.

### 2-1. 제너레이터(Generator)란?

일반 함수는 결과를 한 번에 모두 반환합니다.

```python
def numbers():
    return [1, 2, 3]
```

실행:

```python
result = numbers()

print(result)
```

출력:

```python
[1, 2, 3]
```

---

하지만 제너레이터는 값을 한 번에 만들지 않고 필요할 때마다 하나씩 생성합니다.

```python
def numbers():
    yield 1
    yield 2
    yield 3
```

실행:

```python
result = numbers()

print(result)
```

출력:

```python
<generator object numbers at 0x000001F3>
```

즉,

```python
yield
```

를 사용하는 함수는 자동으로 Generator 객체가 됩니다.

### 2-5. for 문과 Generator

실제로 for문은 내부적으로 next()를 호출합니다.

```python
def numbers():
    yield 1
    yield 2
    yield 3

for n in numbers():
    print(n)
```

동작

```python
gen = numbers()

while True:
    try:
        n = next(gen)
        print(n)
    except StopIteration:
        break
```

LLM 객체를 생성할 때 스트리밍 기능을 활성화해야 합니다.

### llm.stream(messages)

invoke() 대신 stream() 메서드를 사용합니다. 이 메서드는 반복 가능한 객체(Iterable)를 반환합니다.

```python
for chunk in llm.stream(messages):
    # chunk는 응답의 일부분(조각)을 담고 있는 객체입니다.
    print(chunk.content)
```

### chunk.content

* 스트리밍 중에는 전체 답변이 아니라 현재 생성된 '한 조각(chunk)'이 들어옵니다.
* chunk.content를 통해 해당 조각의 텍스트 내용을 가져옵니다.
