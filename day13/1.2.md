# pdf 문서 전처리기

파이썬을 활용한 PDF 문서 전처리는 주로 **텍스트 추출, 데이터 정제(Cleaning), 그리고 구조화**의 과정을 거칩니다. PDF는 데이터 포맷 중에서 전처리가 까다로운 편에 속하는데, 텍스트가 이미지 형태로 되어 있거나 레이아웃이 깨지기 쉽기 때문입니다.

---

## 1. PDF 전처리 전체 프로세스

일반적인 PDF 전처리 파이프라인은 다음과 같은 4단계로 진행됩니다.

1. **문서 유형 파악:** 텍스트 추출이 가능한 '디지털 PDF'인지, 스캔된 '이미지 PDF'인지 확인합니다.
2. **텍스트 및 데이터 추출:** 라이브러리를 사용해 PDF에서 텍스트, 표, 이미지를 뽑아냅니다.
3. **텍스트 정제 (Cleaning):** 불필요한 공백, 특수문자, 불용어(Stopwords) 등을 제거합니다.
4. **구조화 및 토큰화:** 자연어 처리(NLP) 모델이나 LLM에 입력할 수 있도록 문장/문단 단위로 쪼갭니다(Chunking).

---

## 2. 1단계: PDF 유형별 라이브러리 선택

PDF의 상태에 따라 사용하는 파이썬 라이브러리가 달라집니다.

| PDF 유형                 | 추천 라이브러리                         | 특징                                                  |
| ------------------------ | --------------------------------------- | ------------------------------------------            |
| **일반 텍스트 PDF**      | `PyMuPDF (fitz)`, `PyPDF`, `pdfplumber` | 속도가 빠르고 텍스트 및 좌표 추출에 용이              |
| **표(Table)가 많은 PDF** | `pdfplumber`, `Camelot`                 | 표 구조를 인식하여 데이터프레임(Pandas)으로 변환 가능 |
| **스캔된 이미지 PDF**    | `pytesseract` (OCR), `EasyOCR`          | 이미지를 분석하여 텍스트를 읽어냄 (속도 느림)         |

---

## 3. 2단계: 코드로 보는 전처리 절차

가장 범용적이고 속도가 빠른 `PyMuPDF(fitz)`와 표 추출에 강한 `pdfplumber`를 활용한 예시입니다.

PyMuPDF 라이브러리를 사용할 때 이름은 fitz, pymupdf 두가지를 사용할 수 있습니다.

**두 방식 모두 동일한 라이브러리를 가져오는 것이 맞으며 기능적인 차이는 전혀 없습니다.** 하지만 왜 이름을 다르게 쓰는지, 그리고 어떤 방식을 사용하는 것이 좋은지 알아보겠습니다.

---

### 1. 왜 이름이 두 개일까? (역사적 배경)

* **`import fitz` (과거 및 전통적인 방식):** PyMuPDF는 원래 **MuPDF**라는 가볍고 빠른 PDF 렌더링 엔진을 파이썬에서 쓸 수 있도록 만든 라이브러리입니다. 이 MuPDF의 핵심 그래픽 라이브러리 엔진 이름이 바로 'Fitz'였습니다. 그래서 개발자가 처음에 패키지 이름을 `fitz`로 등록했고, 오랫동안 이 방식으로 사용되어 왔습니다.
* **`import pymupdf` (최신 방식):** 설치할 때는 `pip install pymupdf`라고 해놓고, 정작 코드에서는 `import fitz`라고 쓰다 보니 "설치 이름과 임포트 이름이 달라서 헷갈린다"는 사용자들의 불만이 수년간 지속되었습니다. 이에 따라 PyMuPDF 개발팀이 최근 버전부터 `import pymupdf`로도 라이브러리를 불러올 수 있도록 패키지 구조를 업데이트했습니다.

---

### 2. 두 방식의 장단점 비교

| 항목 | `import fitz` | `import pymupdf` |
| --- | --- | --- |
| **인식성** | 설치 이름(`pymupdf`)과 달라 초보자에게 혼동을 줌 | 설치 이름과 같아서 직관적이고 가독성이 좋음 |
| **레거시/예제** | 인터넷상의 **90% 이상**의 기존 예제 코드가 이 방식을 사용함 | 비교적 최근에 도입되어 인터넷 예제 코드가 적은 편임 |
| **이름 충돌 위험** | `fitz`라는 다른 독립 패키지가 존재하여 꼬일 위험이 있음 | 충돌 위험 없이 안전함 |

> **⚠️ `import fitz` 사용 시 주의할 점 (이름 충돌 이슈)**
> 파이썬 패키지 중에는 PyMuPDF와 무관한 정적 사이트 생성기용 `fitz`라는 다른 패키지가 존재합니다. 만약 실수로 `pip install fitz`를 해버리면 PyMuPDF가 정상 작동하지 않는 해프닝이 발생하곤 합니다. (반드시 `pip install pymupdf`로 설치해야 합니다.)

---

### 3. 결론: 무엇을 써야 할까요?

**현재 시점에서는 `import pymupdf` 방식을 더 권장합니다.** 코드가 훨씬 직관적이고 명확해지기 때문입니다.

다만, 깃허브나 블로그 등에서 기존 코드를 복사해서 사용할 때는 여전히 `fitz`로 되어 있는 경우가 많으므로, 두 가지가 결국 **똑같은 것**이라는 것만 기억하시면 됩니다.

* **최신 권장 스타일:**

```python
import pymupdf

doc = pymupdf.open("example.pdf")

```

* **전통적인 스타일 (호환성 유지):**

```python
import fitz

doc = fitz.open("example.pdf")

```

여기에서는 최신 권장 스타일을 사용하겠습니다

### 4. 텍스트 추출하기 (PyMuPDF 활용)

먼저 라이브러리를 설치합니다.

```bash
pip install pymupdf

```

파이썬 코드로 텍스트를 추출하는 기본 구조입니다.

파일명 : step1.py

```python
import pymupdf  # PyMuPDF
import os

pdf_file_path = "data/과정기반 작물모형을 이용한 웹 기반 밀 재배관리 의사결정 지원시스템 설계 및 구축.pdf"  # PDF 파일 경로
doc = pymupdf.open(pdf_file_path) # PDF 문서 열기

full_text = ""

for page in doc: # 페이지 단위로 반복
    text = page.get_text("text")  # 페이지에서 텍스트 추출
    # 'text' 외에 'blocks'나 'words' 구조로 추출도 가능
    full_text += text

# 추출된 텍스트를 txt 파일로 저장
pdf_file_name = os.path.basename(pdf_file_path)  # PDF 파일 이름 추출
pdf_file_name = os.path.splitext(pdf_file_name)[0]  # 확장자 제거
with open(f"output/{pdf_file_name}.txt", "w", encoding="utf-8") as f:
    f.write(full_text)

doc.close()  # 문서 닫기

print(f"PDF 파일에서 텍스트를 추출하여 data/{pdf_file_name}.txt 파일로 저장했습니다.")

```

### ② 텍스트 정제하기 (Cleaning)

추출된 데이터에는 줄바꿈 오류(`\n`), 무의미한 공백, 페이지 번호, 헤더/푸터 등의 노이즈가 섞여 있습니다.

정규표현식(`re`)을 활용해 정제합니다.

파일명 : step2.py

```python
# PDF 파일에서 헤더와 푸터를 제외한 텍스트 추출하기
import pymupdf  # PyMuPDF
import os

pdf_file_path = "data/과정기반 작물모형을 이용한 웹 기반 밀 재배관리 의사결정 지원시스템 설계 및 구축.pdf"  # PDF 파일 경로
doc = pymupdf.open(pdf_file_path) # PDF 문서 열기

# 헤더와 푸터의 높이 설정 (예시로 80 픽셀로 설정)
header_height = 80
footer_height = 80

full_text = ""

for page in doc: # 페이지 단위로 반복
    rect = page.rect  # 페이지의 전체 영역
    # 헤더와 푸터를 제외한 영역 계산
    header = page.get_text(clip=(0,0,rect.width, header_height))  # 헤더 영역
    footer = page.get_text(clip=(0, rect.height - footer_height, rect.width, rect.height))  # 푸터 영역
    content = page.get_text(clip=(0, header_height, rect.width, rect.height - footer_height))  # 콘텐츠 영역

    # 'text' 외에 'blocks'나 'words' 구조로 추출도 가능
    full_text += content + "\n--------------------------------\n"  # 콘텐츠 영역의 텍스트만 추가

# 추출된 텍스트를 txt 파일로 저장
pdf_file_name = os.path.basename(pdf_file_path)  # PDF 파일 이름 추출
pdf_file_name = os.path.splitext(pdf_file_name)[0]  # 확장자 제거

# 헤더와 푸터를 제외한 텍스트를 저장
with open(f"data/{pdf_file_name}_with_preprocessing.txt", "w", encoding="utf-8") as f:
    f.write(full_text)

doc.close()  # 문서 닫기

print(f"PDF 파일에서 텍스트를 추출하여 data/{pdf_file_name}_with_preprocessing.txt 파일로 저장했습니다.")

```

# PDF 파일에서 헤더와 푸터를 제외한 텍스트 추출하기
# PyMuPDF 라이브러리를 사용하여 PDF 파일에서 텍스트를 추출할 때, 페이지의 헤더와 푸터를 제외한 본문 텍스트만 추출하는 방법을 보여줍니다.
# 헤더와 푸터의 높이를 설정하여 해당 영역을 제외한 텍스트를 추출합니다. 추출된 텍스트는 txt 파일로 저장됩니다.
# 한글, 영어, 숫자, 기본 문장부호만 남기기 모든 제어 문자 제거하기
import pymupdf  # PyMuPDF
import os
import regex as re
import unicodedata

pdf_file_path = "data/과정기반 작물모형을 이용한 웹 기반 밀 재배관리 의사결정 지원시스템 설계 및 구축.pdf"  # PDF 파일 경로
doc = pymupdf.open(pdf_file_path) # PDF 문서 열기

# 헤더와 푸터의 높이 설정 (예시로 80 픽셀로 설정)
header_height = 80
footer_height = 80

full_text = ""

for page in doc: # 페이지 단위로 반복
    rect = page.rect  # 페이지의 전체 영역
    # 헤더와 푸터를 제외한 영역 계산
    header = page.get_text(clip=(0,0,rect.width, header_height))  # 헤더 영역
    footer = page.get_text(clip=(0, rect.height - footer_height, rect.width, rect.height))  # 푸터 영역
    content = page.get_text(clip=(0, header_height, rect.width, rect.height - footer_height))  # 콘텐츠 영역

    # 'text' 외에 'blocks'나 'words' 구조로 추출도 가능
    full_text += content + "\n--------------------------------\n"  # 콘텐츠 영역의 텍스트만 추가

# 한글, 영어, 숫자, 공백, 기본 문장부호(.,!?~()-)를 제외한 모든 문자 제거
#match_pattern = r'[^가-힣a-zA-Z0-9\s.,!?~\(\)\-\_]'
#full_text = re.sub(match_pattern, '', full_text)

# 유니코드 카테고리가 'C'(Control)인 것들을 지우되, 
# 오직 일반 줄바꿈(\n)과 일반 탭(\t), 캐리지 리턴(\r)만 살려둡니다.
full_text = "".join(
    ch for ch in full_text
    if not unicodedata.category(ch).startswith("C") or ch in ["\n", "\t", "\r"]
)

# 추출된 텍스트를 txt 파일로 저장
pdf_file_name = os.path.basename(pdf_file_path)  # PDF 파일 이름 추출
pdf_file_name = os.path.splitext(pdf_file_name)[0]  # 확장자 제거

# 헤더와 푸터를 제외한 텍스트를 저장
with open(f"output/{pdf_file_name}_with_preprocessing2.txt", "w", encoding="utf-8") as f:

print(f"PDF 파일에서 텍스트를 추출하여 output/{pdf_file_name}_with_preprocessing2.txt 파일로 저장했습니다.")

### ③ 표(Table) 데이터 따로 추출하기 (pdfplumber 활용)

텍스트 중간에 표가 섞여 있으면 일반 텍스트 추출 시 행과 열이 뒤섞여 엉망이 됩니다. 이때는 `pdfplumber`로 표만 따로 뽑아내는 것이 좋습니다.

```bash
pip install pdfplumber pandas

```

파일명 : step4.py

```python
# PDF 파일에서 표(Table)를 추출하기 위한 라이브러리
import pdfplumber

# 표 데이터를 DataFrame 형태로 다루기 위한 라이브러리
import pandas as pd


# 분석할 PDF 파일 경로
pdf_path = "data/과정기반 작물모형을 이용한 웹 기반 밀 재배관리 의사결정 지원시스템 설계 및 구축.pdf"

# 추출된 모든 표(DataFrame)를 저장할 리스트
all_tables = []


# PDF 파일 열기
# with 구문을 사용하면 작업 종료 후 자동으로 파일이 닫힘
with pdfplumber.open(pdf_path) as pdf:

    # PDF 페이지는 0부터 시작
    # 따라서 PDF 문서의 6페이지는 index=5
    page = pdf.pages[5]

    # 현재 페이지의 크기 출력
    print(f"페이지 크기 : {page.width} x {page.height}")

    # ----------------------------------------------------
    # 표 추출
    # ----------------------------------------------------
    # extract_tables()
    # 현재 페이지에서 인식된 모든 표를 리스트 형태로 반환
    #
    # 반환 예시
    # [
    #     [
    #         ["이름","나이","직업"],
    #         ["홍길동","30","개발자"],
    #         ["김철수","25","학생"]
    #     ],
    #     ...
    # ]
    # ----------------------------------------------------
    tables = page.extract_tables()

    # 발견된 표 개수 출력
    print(f"\n발견된 표 개수 : {len(tables)}")

    # ----------------------------------------------------
    # 추출된 표들을 하나씩 처리
    # ----------------------------------------------------
    for idx, table in enumerate(tables):

        print(f"\n{'='*60}")
        print(f"TABLE {idx+1}")
        print(f"{'='*60}")

        # ------------------------------------------------
        # 리스트 형태의 표를 DataFrame으로 변환
        # ------------------------------------------------
        df = pd.DataFrame(table)

        # 현재 상태 예시
        #
        #        0      1      2
        # 0    이름    나이   직업
        # 1  홍길동    30   개발자
        # 2  김철수    25    학생

        # ------------------------------------------------
        # 첫 번째 행을 컬럼명(Header)으로 지정
        # ------------------------------------------------
        df.columns = df.iloc[0]

        # 첫 번째 행은 이미 컬럼명으로 사용했으므로 제거
        df = df[1:].reset_index(drop=True)

        # 결과 예시
        #
        #     이름    나이   직업
        # 0 홍길동   30   개발자
        # 1 김철수   25    학생

        # 추출된 표를 리스트에 저장
        all_tables.append(df)

        # 표 내용 출력
        print(df)

        # ------------------------------------------------
        # CSV 파일로 저장
        # ------------------------------------------------
        csv_file = f"table_{idx+1}.csv"

        # utf-8-sig
        # 엑셀에서 한글 깨짐 방지를 위해 사용
        df.to_csv(
            csv_file,
            index=False,        # 인덱스 저장 안함
            encoding="utf-8-sig"
        )

        print(f"\n저장 완료 : {csv_file}")


# --------------------------------------------------------
# 전체 표 개수 확인
# --------------------------------------------------------
print(f"\n총 저장된 표 개수 : {len(all_tables)}")


```

## CID Font PDF

CID Font는 **Character Identifier Font**의 약자로, Adobe가 일본어·중국어·한국어(CJK)처럼 글자 수가 매우 많은 언어를 지원하기 위해 만든 폰트 기술입니다. 일반적인 서양 폰트가 수백 개의 문자만 관리하면 되지만, 한글·한자·일본어는 수천~수만 개의 글자를 다뤄야 하기 때문에 별도의 구조가 필요했습니다. ([위키백과][1])

### 일반 폰트와 CID Font의 차이

| 구분        | 일반 폰트       | CID Font               |
| ----------- | --------------- | ---------------------- |
| 대상 문자   | 영문, 숫자 중심 | 한글, 한자, 일본어     |
| 문자 수     | 수백 개         | 수천~수만 개           |
| 내부 식별   | 문자 코드 기반  | CID(Character ID) 기반 |
| PDF 지원    | 가능            | 가능                   |
| CMap 사용   | 없음            | 사용                   |

CID Font는 문자 자체를 직접 관리하지 않고 각 글자에 **CID 번호**를 부여합니다.

예)

```text
CID 1000 → 가
CID 1001 → 나
CID 1002 → 다
```

그리고 실제 문자 코드(Unicode)와 CID를 연결하는 역할을 하는 것이 **CMap(Character Map)** 입니다. ([위키백과][1])

## PDF에서 왜 중요할까?

PDF 내부에는 다음과 같이 저장될 수 있습니다.

```text
Unicode 문자
    ↓
CMap
    ↓
CID 번호
    ↓
Glyph(글자 모양)
```

즉 PDF에서

```python
"삼성전자"
```

라는 글자를 추출하려고 할 때

```python
CID 5234
CID 8123
CID 9411
CID 1122
```

와 같이 저장되어 있으면

1. CMap 해석
2. CID → Unicode 변환

과정을 거쳐야 실제 문자열을 얻을 수 있습니다.

이 과정이 실패하면 PDF 추출 결과가

```text
����
```

또는

```text
cid:5234 cid:8123 ...
```

처럼 나타납니다. ([위키백과][1])

파일명 : step4-1.py

```python
import pymupdf  # PyMuPDF
import easyocr
import pandas as pd

# 1. PDF의 해당 페이지를 고해상도 이미지로 변환
pdf_path = "data/과정기반 작물모형을 이용한 웹 기반 밀 재배관리 의사결정 지원시스템 설계 및 구축.pdf"
doc = pymupdf.open(pdf_path)

# 예시: 표가 있는 페이지 번호 지정 (0부터 시작하므로 3페이지면 2)
page_number = 5  
page = doc.load_page(page_number)

# 해상도를 높이기 위해 matrix 설정 (zoom=2는 2배 선명하게)
zoom = 2
mat = pymupdf.Matrix(zoom, zoom)
pix = page.get_pixmap(matrix=mat)
image_path = "pdf_page_high_res.png"
pix.save(image_path)

print(f"[1] {page_number + 1}페이지를 이미지로 변환 완료: {image_path}")

# 2. EasyOCR 모델 로드 (한글과 영어 지정)
reader = easyocr.Reader(['ko', 'en'])
print("[2] OCR 모델 로드 완료. 텍스트 판독을 시작합니다...")
result = reader.readtext(image_path)

# 3. 추출된 데이터를 Y축(행) 기준으로 정렬 및 구조화
# EasyOCR 결과 구조: [([[x1,y1], [x2,y2], [x3,y3], [x4,y4]], "텍스트", 신뢰도)]
ocr_data = []
for bbox, text, prob in result:
    top_left_x = bbox[0][0]  # 텍스트 박스의 좌측 X축 좌표
    top_left_y = bbox[0][1]  # 텍스트 박스의 상단 Y축 좌표
    ocr_data.append({'x': top_left_x, 'y': top_left_y, 'text': text.strip()})

# Y축 좌표를 기준으로 정렬 (같은 행에 있는 글자들을 묶기 위함)
# Y축 좌표 차이가 15~20 픽셀 이하이면 같은 행(Row)으로 간주합니다.
ocr_df = pd.DataFrame(ocr_data)
ocr_df = ocr_df.sort_values(by=['y', 'x']).reset_index(drop=True)

print("\n--- [OCR 추출 결과] ---")
current_y = -999
row_text = []
threshold = 20  # 같은 행으로 판정할 Y축 오차 범위 (글자 크기에 따라 조절)

for index, row in ocr_df.iterrows():
    if current_y == -999:
        current_y = row['y']
        row_text.append(row['text'])
    elif abs(row['y'] - current_y) <= threshold:
        row_text.append(row['text'])
    else:
        # 새로운 행 시작 시 이전 행 출력
        print("\t".join(row_text))
        row_text = [row['text']]
        current_y = row['y']

# 마지막 행 출력
if row_text:
    print("\t".join(row_text))

```
