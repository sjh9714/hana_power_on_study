# Docling 라이브러리 소개

Docling은 IBM Research가 개발한 오픈소스 문서 이해(Document Understanding) 라이브러리로, PDF, Word, PowerPoint, Excel, 이미지 등의 문서를 AI가 활용하기 좋은 구조화 데이터로 변환하는 도구입니다. 특히 RAG(Retrieval-Augmented Generation), VectorDB 구축, 문서 검색, Agent 시스템 개발에 최적화되어 있습니다. ([GitHub][1])

## Docling이 등장한 이유

기존 라이브러리들은 다음과 같은 문제가 있습니다.

| 라이브러리 | 특징            |
| ---------- | --------------- |
| PyPDF2     | 텍스트만 추출   |
| pdfplumber | 표 추출 가능    |
| PyMuPDF    | 빠른 PDF 처리   |
| OCR 도구   | 스캔 문서 처리  |

하지만 실제 기업 문서는

```text
제목
본문
표
이미지
수식
코드
각주
```

구조를 가지고 있습니다.

기존 방식은 이러한 구조를 잃어버리기 쉽습니다.

Docling은 문서의 레이아웃과 구조를 이해하여 AI가 사용할 수 있는 형태로 변환합니다. ([Docling Project][2])

# 주요 특징

## 1. 다양한 문서 형식 지원

지원 포맷

```text
PDF
DOCX
PPTX
XLSX
HTML
Markdown
LaTeX
이미지(JPEG, PNG, TIFF)
WAV
MP3
WebVTT
EML
MSG
```

등을 하나의 API로 처리할 수 있습니다. ([GitHub][1])

---

## 2. 고급 PDF 이해

일반 PDF 파서와 가장 큰 차이점입니다.

Docling은

```text
Page Layout
Reading Order
Table Structure
Formula
Code Block
Image
Caption
```

을 인식합니다. ([GitHub][1])

예)

```python
from docling.document_converter import DocumentConverter

converter = DocumentConverter()
result = converter.convert("sample.pdf")
```

---

## 3. 표(Table) 인식

금융문서, 사업보고서, 논문에서 매우 중요합니다.

예)

```text
상품명    수익률
ABC펀드   12.5%
XYZ펀드   8.2%
```

같은 표를

```python
DataFrame
```

형태로 변환할 수 있습니다.

Docling은 IBM의 TableFormer 모델을 사용하여 복잡한 표 구조를 분석합니다. ([IBM Research][3])

---

## 4. OCR 지원

스캔 PDF 처리 가능

예)

```text
종이 문서
↓
스캔 PDF
↓
OCR
↓
구조화 데이터
```

OCR 기능을 통해

* 금융 서류
* 의료 기록
* 계약서

등도 처리 가능합니다. ([IBM][4])

---

## 5. 다양한 출력 형식

### Markdown

```python
md = result.document.export_to_markdown()
```

출력

```markdown

# 투자설명서

## 투자목적

내용...

| 상품명 | 수익률 |
|--------|--------|
| A      | 10%    |
```

---

### JSON

```python
json_data = result.document.export_to_dict()
```

출력

```json
{
  "title": "...",
  "sections": [...],
  "tables": [...]
}
```

---

### HTML

```python
export_to_html()
```

등을 지원합니다. ([GitHub][1])

# 내부 구조

Docling은 모든 문서를 다음 구조로 통일합니다.

```text
DoclingDocument
 ├── Title
 ├── Section
 ├── Paragraph
 ├── Table
 ├── Figure
 ├── Formula
 └── Metadata
```

이 덕분에

```text
PDF
DOCX
PPTX
```

를 동일한 코드로 처리할 수 있습니다. ([GitHub][1])

# 사용 예제

```python
from docling.document_converter import DocumentConverter

converter = DocumentConverter()

result = converter.convert("report.pdf")

markdown = result.document.export_to_markdown()

print(markdown)
```
