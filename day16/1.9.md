# `agri_rag_chatbot_langgraph5` 프로젝트

실제 운영 환경에서는 **Prompt를 Python 소스에 하드코딩하는 방식은 거의 사용하지 않습니다.**

현재 프로젝트를 보면

```python
router_prompt = PromptTemplate.from_template("""
...
""")
```

처럼 되어 있는데, 교육용/실습용으로는 좋지만 운영 환경에서는 관리가 어렵습니다.

문제가 많습니다.

```text
1. Prompt 수정 시 코드 수정 필요
2. Git Commit 필요
3. 서버 재배포 필요
4. 서비스 재시작 필요
5. Prompt 버전 관리 어려움
6. Prompt A/B 테스트 어려움
```

실무에서는 보통 다음 4단계로 발전합니다.

# Prompt YAML 관리

```text
prompts/

```

예)

```yaml
router:
  version: "1.0"

  template: |
    당신은 질문 분류기입니다.

    질문:
    {query}

    답:

rag:
  version: "1.0"

  template: |
    다음 문서를 참고하여 답변하세요.

    문서:
    {context}

    질문:
    {query}
```

로드

```python
import yaml

with open(
    "prompts/prompts.yaml",
    encoding="utf-8"
) as f:
    config = yaml.safe_load(f)

router_prompt = PromptTemplate.from_template(
    config["router"]["template"]
)
```

장점

```text
Prompt
Version
설정값

모두 관리 가능
```

# 현재 프로젝트에 적용한 방법

현재 프로젝트 규모라면

```text
agri_rag_chatbot_langgraph5/

├── prompts/
│   ├── router_prompt.txt
│   ├── rag_prompt.txt
│   ├── react_prompt.txt
│   └── agent_prompt.txt
```

그리고 PromptLoader를 하나 만듭니다.

```python
# common/prompt_loader.py

from pathlib import Path

class PromptLoader:

    @staticmethod
    def load(name):

        return Path(
            f"prompts/{name}.txt"
        ).read_text(
            encoding="utf-8"
        )
```

사용

```python
from common.prompt_loader import PromptLoader

router_prompt = PromptTemplate.from_template(
    PromptLoader.load(
        "router_prompt"
    )
)
```

그러면

```text
Prompt 수정
 ↓
파일 저장
 ↓
다음 질문부터 즉시 적용
```

이 가능합니다.
