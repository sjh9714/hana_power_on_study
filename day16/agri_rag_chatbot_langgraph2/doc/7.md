# 수업 중 강조

```text
학생들이 만드는 대부분의 RAG는

본문 검색만 가능합니다.

하지만 실제 기업 검색 시스템은

연도

저자

부서

카테고리

프로젝트

문서등급

등을 함께 검색합니다.

Self Query Retriever는

사용자가 필터 문법을 몰라도

자연어만으로 검색하게 만드는 기술입니다.
```

# 예상 질문

### Q1

Metadata가 없으면 사용할 수 없나요?

A.

사실상 어렵습니다.

Self Query Retriever는 Metadata 기반 검색 기술입니다.

---

### Q2

농업 논문 PDF는 Metadata가 없는데요?

A.

PDF 적재 시 직접 Metadata를 생성해야 합니다.

예:

```python
metadata = {
    "year":2024,
    "author":"김솔희",
    "crop":"밀"
}
```

---

### Q3

모든 질문에 Self Query를 적용해야 하나요?

A.

아닙니다.

연도, 저자, 카테고리 등 필터 조건이 포함된 질문에 특히 효과적입니다.

## 주관식

### 3

왜 Self Query Retriever가 일반 Vector Search보다 더 강력한 검색을 제공하는지 설명하시오.

### 모범답안

```text
Self Query Retriever는 사용자의 자연어 질문을 분석하여
검색어(Query)와 Metadata Filter를 자동 생성한다.

따라서 본문 검색뿐 아니라
연도, 저자, 카테고리 같은 구조화된 조건을 함께 사용할 수 있어
더 정확하고 실무적인 검색이 가능하다.
```
