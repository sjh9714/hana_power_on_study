위 기능을 구현하기 위해서는 이전에 작업한 것 같이 get_session_history() 이용하여 처리하시면 됩니다.

## 1. 단계

세션 히스토리에서 이전 대화 기록을 가져옵니다.
ReAct Agent가 이전 대화 맥락을 이해할 수 있도록 메시지 목록을 구성합니다.

## 2. 단계

이전 대화 기록에 현재 사용자 메시지를 추가하여 전체 메시지 리스트를 생성합니다.

## 3. 단계

Graph 실행시 이전 대화 기록과 현재 사용자 메시지를 전달합니다.

## 4. 단계

세션 히스토리에 현재 대화 내용을 저장합니다.
AI 응답을 세션 히스토리에 추가합니다.

수정된 코드

파일명 : chat_service.py

```python
        # LangGraph ReAct Agent 그래프 생성
        graph = create_graph(
            selected_model=selected_model,
            session_id=session_id
        )

        # 세션 히스토리에서 이전 대화 기록을 가져옵니다.
        # ReAct Agent가 이전 대화 맥락을 이해할 수 있도록 메시지 목록을 구성합니다.
        chat_history  = get_session_history(session_id)

        # 이전 대화 기록에 현재 사용자 메시지를 추가하여 전체 메시지 리스트를 생성합니다.
        messages = chat_history.messages + [
            HumanMessage(content=message)
        ]

        # Graph 실행
        result = graph.invoke(
            {
                "messages": messages,

                "session_id": session_id,

                "user_question": message,

                "final_answer": ""
            }
        )

        answer = result["final_answer"]

        # 
        # 세션 히스토리에 현재 대화 내용을 저장합니다.
        # ReAct Agent는 내부적으로 메모리를 관리하지 않으므로, 
        # 실행이 끝난 후 수동으로 사용자 메시지와 AI 응답을 히스토리에 추가합니다.
        chat_history.add_user_message(message)

        # AI 응답을 세션 히스토리에 추가합니다.
        chat_history.add_ai_message(
            result["final_answer"]
        )

```
