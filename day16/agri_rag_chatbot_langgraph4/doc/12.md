# 최종 시험 문제

### 1

Enterprise RAG에서 가장 중요한 요소 5가지를 설명하시오.

---

### 2

Self Query → Multi Query → ReRank → Parent Retriever → Compression 순서가 필요한 이유를 설명하시오.

---

### 3

GraphRAG와 Vector RAG의 차이를 설명하시오.

---

### 4

Agentic RAG가 일반 RAG보다 우수한 이유를 설명하시오.

---

### 5

사용자의 Kubernetes 환경(master + node1~3)에 agri_rag_chatbot Enterprise Edition을 배치하는 구조를 설계하시오.

# 제3권 전체 요약

제3권에서는 다음을 완성했습니다.

```text
1. Re-Ranker
2. Multi Query Retriever
3. Parent Retriever
4. Contextual Compression
5. Self Query Retriever
6. Agentic RAG
7. GraphRAG
8. RAG Evaluation
9. LLMOps
10. Enterprise Architecture
```

이제 다음 단계로는 **제4권: LangGraph 기반 Multi-Agent AI Platform 구축**을 진행할 수 있습니다.

포함 예정 주제:

```text
Supervisor Agent
Research Agent
RAG Agent
Code Agent
SQL Agent
Tool Agent
Human-in-the-Loop
Multi-Agent Orchestration
MCP(Model Context Protocol)
A2A(Agent-to-Agent)
```

이는 현재의 Agentic RAG를 넘어 **AI 에이전트 플랫폼 아키텍트 수준**의 과정입니다.
