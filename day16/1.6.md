# `agri_rag_chatbot_langgraph2` 프로젝트는 AUTO와 REACT 처리 루틴을 합친 구조

## 처리방법

1. 분류에 대한 Prompt를 수정
2. chat()에서 REACT로 동작 하는 부분을 AUTO와 같이 사용하게 수정함 

Uvicorn을 사용하여 FastAPI 앱 실행

```bash
uvicorn app:app --reload
```

실행시 아래 질문 해보세요

```bash
mode 선택 AUTO, REACT 후 - 현재 시간을 알려줘
mode 선택 AUTO, REACT 후 - 계산 100 + 200 * 3
mode 선택 AUTO, REACT 후 - DOCKER에 대하여 설명해줘 
mode 선택 AUTO, REACT 후 - 밀 재배관리 시스템에 대하여 설명해줘 

REACT에서는 이전 질문 기억하지 못함 아래 질문으로 확인하세요 
mode 선택 AUTO, REACT 후 - 나의 이름은 홍길동
mode 선택 AUTO, REACT 후 - 나의 이름은? 
```
