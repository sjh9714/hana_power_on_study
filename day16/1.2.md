# LangGraph란?

LangGraph는 [LangGraph 공식 문서](https://langchain-ai.github.io/langgraph/?utm_source=chatgpt.com) 에서 제공하는 **LLM 애플리케이션을 그래프(Graph) 형태로 설계하는 프레임워크**입니다.

쉽게 말하면:

* LangChain = 체인(Chain) 방식
* LangGraph = 상태(State) + 그래프(Graph) 방식

기존 LangChain은 보통 다음처럼 순차적으로 동작합니다.

```text
질문
 ↓
RAG 검색
 ↓
LLM
 ↓
답변
```

반면 LangGraph는

```text
          ┌──────────┐
          │ 질문분석 │
          └────┬─────┘
               │
      ┌────────┴────────┐
      │                 │
      ▼                 ▼
   RAG 검색          Tool 선택(계산기)
      │                 │
      └────────┬────────┘
               ▼
            답변생성
```

처럼 조건에 따라 다른 경로를 선택할 수 있습니다.

---

# LangGraph의 핵심 개념

## 1. State

상태(State)를 공유합니다.

```python
{
    "question": "...",
    "documents": [],
    "answer": ""
}
```

모든 노드가 같은 State를 수정합니다.

---

## 2. Node

실행 함수입니다.

```python
def search(state):
    ...
```

---

## 3. Edge

노드 연결입니다.

```python
START -> search -> answer -> END
```

---

## 4. Conditional Edge

조건 분기

```python
if finance:
    finance_node

if weather:
    weather_node
```

---

# LangGraph를 요소를 일반 프로그램과 비교

| 일반 프로그램  | LangGraph        |
| -------------- | ---------------- |
| 공유 변수      | State            |
| 함수           | Node             |
| 함수 호출      | Edge             |
| if / switch    | Conditional Edge |
| main()         | START            |
| return         | END              |

## Graph 생성

Graph 생성이란? 노드 등록 + 노드 연결 + 시작/종료 정의하는 것을 의미합니다.

---

### 노드 등록이란?

LangGraph에서 노드 등록(add_node) 은 본질적으로 "이 노드 이름이 실행되면 어떤 함수를 호출할지 등록한다." 는 의미입니다.

### 노드 연결이란?

LangGraph에서 노드 연결(add_edge)이란 어떤 노드 함수를 실행되고 다음에 어떤 노드 함수를 실행할지 정의하는 것입니다.

예를 들어,

```python
graph_builder.add_edge("chatbot", "answer")
```

의 의미는

```text
chatbot 노드 실행 후
answer 노드를 실행하라
```

입니다.

즉,

```text
chatbot() ───► answer()
```

라는 **실행 흐름(Flow)** 을 만드는 것입니다.

---

### START, END도 사실은 특별한 노드

LangGraph 내부에서는

```python
from langgraph.graph import START, END
```

를 제공합니다.

이것도 개념적으로는 노드입니다.

```python
graph_builder.add_edge(START, "chatbot")
```

의 의미는

```text
START
  │
  ▼
chatbot
```

즉

> "그래프가 시작되면 chatbot 노드부터 실행하라"

입니다.

---

반대로

```python
graph_builder.add_edge("answer", END)
```

는

```text
answer
   │
   ▼
 END
```

즉

> "answer 실행 후 그래프를 종료하라"

입니다.

---

### 따라서 add_edge()의 본질

add_edge()는

```python
graph_builder.add_edge(출발노드, 도착노드)
```

형태이며

```text
출발노드 → 도착노드
```

를 정의합니다.

예:

```python
graph_builder.add_edge("router", "time")
```

```text
router() → time()
```

예:

```python
graph_builder.add_edge("time", "answer")
```

```text
time() → answer()
```

예:

```python
graph_builder.add_edge("answer", END)
```

```text
answer() → END
```

---

그래서 보통 이렇게 이해합니다.

| 함수                 | 의미           |
| -------------------- | -------------- |
| `add_node()`         | 노드 등록      |
| `add_edge()`         | 노드 연결      |
| `add_edge(START, x)` | 시작 노드 지정 |
| `add_edge(x, END)`   | 종료 노드 지정 |

```python
add_edge(START, ...)
```

또는

```python
add_edge(..., END)
```

처럼 사용할 때만 특별히 **시작점/종료점 지정** 역할을 하는 것입니다.

그래서 한 문장으로 정리하면:

> **`add_node()`는 "어떤 함수를 사용할지 등록"이고, `add_edge()`는 "등록된 노드들을 어떤 순서로 실행할지 연결"하는 함수입니다. START와 END는 그 연결 과정에서 사용하는 특별한 시작/종료 노드입니다.**

### 분기(라우팅) 규칙을 등록

add_conditional_edges()는 노드 실행 결과에 따라 다음에 실행할 노드를 동적으로 선택하는 분기(라우팅) 규칙을 등록하는 함수입니다.

예시

```python
builder.add_conditional_edges(
    "router",            # router_node() 함수 호출, route 변수에 실행할 함수를 의하는 문자열을 설정됨 
    route_function,      # 공유변수 route 속성에 있는 값을 의미함(실제 router_node()에서 설정된 값)
    {                    # key : value, key는 실제 router_node()에서 route 속성에 설정된 값, value 는 add_node()함수에 의해 등록된 노드이름입니다 
        "time": "time",  # router_node() 함수에서 route 속성에 설정하는 문자열과 add_node()함수에 의해 등록된 노드이름 같이 때문에 오해 할 수 있습니다.
        "calculator": "calculator",  # router_node()에서 route 속성에 설정된 값, add_node()함수에 의해 등록된 노드이름 같을 때는 지금 전달 하는 부분을 생략해도 된다
        "chat": "chat"
    }
)
```

router 노드의 실행 결과(route 값)에 따라 time, calculator, chat 중 다음 실행할 노드를 결정한다.

---

### compile() 이란?

지금까지 등록한 노드와 노드 연결, 시작점, 종료점 정보를 검증하고, 실제 실행 가능한 Graph 객체로 변환하는 과정 입니다.

```python
from langgraph.graph import StateGraph
from langgraph.graph import START, END

# state 객체 생성
graph_builder = StateGraph(State)

# 채팅 함수 선언 
def chatbot_node(state):
    question = state["question"]

    return {
        "answer": f"질문은 {question} 입니다."
    }

# 노드 등록
graph_builder.add_node("chatbot", chatbot_node)

# 노드 연결 
graph_builder.add_edge(START, "chatbot")
graph_builder.add_edge("chatbot", END)

# builder 패턴을 사용하여 Graph 생성합니다 
graph = graph_builder.compile()
```

## 실행

```python
result = graph.invoke(
    {
        "question": "안녕하세요"
    }
)

print(result)
```

출력

```python
{
    'question': '안녕하세요',
    'answer': '질문은 안녕하세요 입니다.'
}
```

## 전체코드

파일명 : step2.py

```python
"""
LangGraph 입문 예제

구조

START
  │
  ▼
Router
  │
  ├─────────► Time
  │
  ├─────────► Calculator
  │
  └─────────► Chat
                    │
                    ▼
                   END

"""

# TypedDict는 State 구조를 정의하기 위해 사용
from typing import TypedDict

# LangGraph 핵심 클래스
from langgraph.graph import StateGraph
from langgraph.graph import START, END

# 현재 시간 조회용
from datetime import datetime


# =====================================================
# State 정의
# =====================================================
#
# State는 모든 Node가 공유하는 메모장
#
# 예)
#
# {
#     "question": "현재 시간 알려줘",
#     "route": "",
#     "answer": ""
# }
#
# Router Node
# Time Node
# Calculator Node
#
# 모두 같은 State를 사용
#
# =====================================================

class AgentState(TypedDict):

    # 사용자 질문
    question: str

    # Router가 결정한 경로
    route: str

    # 최종 답변
    answer: str


# =====================================================
# Router Node
# =====================================================
#
# 역할
#
# 사용자의 질문을 분석하여 어느 Node로 이동할지 결정
#
# 예)
#
# "현재 시간 알려줘"
#   -> time
#
# "100 * 200"
#   -> calculator
#
# "Docker란?"
#   -> chat
#
# =====================================================

def router_node(state: AgentState):

    question = state["question"]

    # 시간 관련 질문
    if "시간" in question:

        route = "time"

    # 계산 관련 질문
    elif "+" in question or "*" in question:

        route = "calculator"

    # 그 외 일반 질문
    else:

        route = "chat"

    print(f"[Router] route = {route}")

    # State 업데이트
    return {
        "route": route
    }


# =====================================================
# Time Node
# =====================================================
#
# 현재 시간을 반환
#
# =====================================================

def time_node(state: AgentState):

    print("[Time Node 실행]")

    now = datetime.now()

    return {
        "answer": f"현재 시간은 {now}"
    }


# =====================================================
# Calculator Node
# =====================================================
#
# 간단한 계산 수행
#
# 예)
#
# 100 * 200
#
# 결과
#
# 20000
#
# =====================================================

def calculator_node(state: AgentState):

    print("[Calculator Node 실행]")

    question = state["question"]

    try:

        # 교육용 예제
        # 실제 서비스에서는 eval 사용 금지
        result = eval(question)

        return {
            "answer": f"계산 결과 : {result}"
        }

    except Exception:

        return {
            "answer": "계산 실패"
        }


# =====================================================
# Chat Node
# =====================================================
#
# 일반 질문 처리
#
# 실제 프로젝트에서는
#
# ChatOpenAI
# ChatOllama
# Gemini
#
# 등을 호출
#
# =====================================================

def chat_node(state: AgentState):

    print("[Chat Node 실행]")

    question = state["question"]

    return {
        "answer": f"일반 질문 처리 : {question}"
    }


# =====================================================
# Routing Function
# =====================================================
#
# Conditional Edge에서 사용
#
# Router가 저장한 route 값을 읽음
#
# route = time
# route = calculator
# route = chat
#
# =====================================================

def route_function(state: AgentState):

    return state["route"]


# =====================================================
# Graph 생성
# =====================================================

builder = StateGraph(AgentState)


# =====================================================
# Node 등록
# =====================================================

builder.add_node("router", router_node)

builder.add_node("time", time_node)

builder.add_node("calculator", calculator_node)

builder.add_node("chat", chat_node)


# =====================================================
# START -> Router
# =====================================================

builder.add_edge(
    START,
    "router"
)


# =====================================================
# Router 조건 분기
# =====================================================
#
# route 값에 따라 이동
#
# time       -> Time Node
# calculator -> Calculator Node
# chat       -> Chat Node
#
# =====================================================

builder.add_conditional_edges(
    "router",
    route_function,
    {
        "time": "time",
        "calculator": "calculator",
        "chat": "chat"
    }
)


# =====================================================
# 각 Node 종료 후 END
# =====================================================

builder.add_edge(
    "time",
    END
)

builder.add_edge(
    "calculator",
    END
)

builder.add_edge(
    "chat",
    END
)


# =====================================================
# Graph 컴파일
# =====================================================
#
# 실제 실행 가능한 Graph 객체 생성
#
# =====================================================

graph = builder.compile()


# =====================================================
# 테스트
# =====================================================

print("\n===== 테스트1 =====")

result = graph.invoke(
    {
        "question": "현재 시간 알려줘",
        "route": "",
        "answer": ""
    }
)

print(result)

print("\n===== 테스트2 =====")

result = graph.invoke(
    {
        "question": "100 * 200",
        "route": "",
        "answer": ""
    }
)

print(result)

print("\n===== 테스트3 =====")

result = graph.invoke(
    {
        "question": "Docker란?",
        "route": "",
        "answer": ""
    }
)

print(result)

```
