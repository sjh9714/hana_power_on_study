# 수업 중 강조

```text
학생들이 만든 RAG는

대부분 질문을 그대로 검색합니다.

하지만 사용자가 질문을 잘하지 못하는 경우가 많습니다.

실무에서는

사용자의 질문을 AI가 먼저 개선하고,

그 다음 검색합니다.

이것이 Multi Query Retriever의 핵심입니다.

즉,

검색을 잘하는 것이 아니라

질문을 잘 만드는 기술입니다.
```

## 주관식

### 3

왜 Multi Query Retriever가 일반 Retriever보다 높은 Recall을 제공하는지 설명하시오.

### 모범답안

```text
Multi Query Retriever는 하나의 질문을 여러 형태의 질문으로 변환하여 검색한다.

각 질문이 서로 다른 문서를 찾을 수 있기 때문에
정답 문서를 발견할 확률(Recall)이 증가한다.

특히 질문 표현과 문서 표현이 다른 경우에 효과가 크다.
```
