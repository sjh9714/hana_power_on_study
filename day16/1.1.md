# LangGraph을 학습하기 전 일반 프로그램으로 로직 작성

>질문 :

- 현재 시간을 알려줘

- 계산 100 + 200 * 3

- 안녕하세요

와 같이 질문을 하고 결과 출력되는 파이썬 프로그램을 작성하고 이를 다시 LangGraph로 작성서 LangGraph를 이해 하려고 합니다.

```text
START
  │
  ▼
Router
  │
  ├─────────► Time
  │
  ├─────────► Calculator
  │
  └─────────► Chat
                    │
                    ▼
                   END
```

---

# 1. 전체 코드

파일명 : step01.py

```python
from datetime import datetime
import re

# =========================
# Tool 1 : Time, 현재 시간 얻기 
# =========================
def get_time():
    now = datetime.now()
    return now.strftime("%Y-%m-%d %H:%M:%S")


# =========================
# Tool 2 : Calculator, 계산기 
# =========================
def calculator(question):
    try:
        expr = question.replace("계산", "").strip()

        # 안전하게 숫자와 연산자만 허용
        if not re.fullmatch(r"[0-9+\-*/(). ]+", expr):
            return "계산식이 올바르지 않습니다."

        result = eval(expr)

        return f"결과 = {result}"

    except Exception as e:
        return f"계산 오류 : {e}"


# =========================
# Tool 3 : Chat, 일반 채팅
# =========================
def chat(question):
    return f"일반 대화 처리 : {question}"


# =========================
# Router, 질문으로 다음에 실행할 함수가 어떤 것인지 찾는다 
# 이것은 간단한 예제로 이해를 하면됨 
# =========================
def router(question):

    question = question.lower()

    # Time Routing
    if "시간" in question:
        return "time"

    # Calculator Routing
    if "계산" in question:
        return "calculator"

    # Default
    return "chat"


# =========================
# Main
# =========================
print("=== Simple Router Agent ===")
print("종료 : exit\n")

while True:

    question = input("질문 > ")

    if question.lower() == "exit":
        break

    route = router(question)

    print(f"[Router] → {route}")

    if route == "time":
        answer = get_time()

    elif route == "calculator":
        answer = calculator(question)

    else:
        answer = chat(question)

    print("답변 :", answer)
    print()

```

# 3. 이 방식의 문제점

현재 Router는 단순 키워드 매칭입니다.

```python
if "시간" in question:
    return "time"

if "계산" in question:
    return "calculator"
```

그래서 아래 질문은 처리 못합니다.

```text
서울 현재 시각 알려줘
```

왜냐하면

```text
시간
```

이라는 단어가 없기 때문입니다.

# 4. LLM을 Router로 사용하는 경우

실무에서는 보통 Router를 LLM이 담당합니다.

```python
def router(question):

    prompt = f"""
    사용자의 질문을 분류하라.

    time
    calculator
    chat

    route = llm.invoke(prompt)

    return route
```

# 5. LangGraph를 한마디로 설명하면

LangGraph는 LLM, Tool, RAG, DB 등을 하나의 프로그램처럼 연결하고, 함수 실행 결과에 따라 분기·반복·상태 관리를 수행할 수 있게 해주는 AI Workflow(오케스트레이션) 라이브러리이다.

현재는

```text
START
  │
  ▼
Router
  │
  ├── Time
  ├── Calculator
  └── Chat
```

정도라면 일반 Python으로 충분합니다.

하지만 기능이 많아지면

```text
START
  │
  ▼
Router
  │
  ├── RAG Search
  ├── SQL Query
  ├── Time
  ├── Weather
  ├── Calculator
  ├── Code Generator
  └── Web Search
            │
            ▼
       Answer Generator
            │
            ▼
           END
```

처럼 흐름이 복잡해집니다.

이때는

* 상태(State) 관리
* 노드(Node) 관리
* 조건 분기
* 반복 루프
* Tool 호출 이력

등을 체계적으로 관리하기 위해 **LangGraph**를 사용합니다.
