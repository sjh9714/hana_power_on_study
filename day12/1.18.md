# Agent란 무엇인가?

LLM(OpenAI GPT, Gemini 등)은 기본적으로 **질문 → 답변**만 수행합니다.

예를 들어

```text
사용자:
100달러를 원화로 환전하면 얼마야?

GPT:
현재 환율을 모르므로 정확한 답변 불가능
```

일반 LLM은 스스로 인터넷 검색을 하거나 계산기를 실행하거나 DB를 조회하지 못합니다.

반면 Agent는

```text
사용자
 ↓
Agent
 ↓
Tool 선택
 ↓
Tool 실행
 ↓
결과 수집
 ↓
최종 답변
```

형태로 동작합니다.

즉,

> Agent는 LLM이 여러 도구(Tool)를 사용하여 목표를 해결할 수 있도록 만든 AI 실행 엔진입니다.

---

```text
475

↓

최종 응답
```

# 비전공자 관점의 한 줄 정리

```text
Chain
=
정해진 순서대로 실행

Agent
=
LLM이 스스로 판단하여 Tool을 선택하고 실행

LangGraph
=
여러 Agent와 Workflow를 상태 기반으로 관리
```

즉,

```text
Prompt → Chain → Agent → LangGraph
```

# 전체 코드

파일명 : step29.py

```python
import os
from langchain.tools import tool
from langchain.agents import create_agent

from langchain_openai import ChatOpenAI


# ---------------------------------
# Tool
# ---------------------------------

@tool
def add(a: int, b: int) -> int:
    """두 숫자를 더한다."""
    print(f"\n[ADD] {a} + {b}")
    return a + b


@tool
def multiply(a: int, b: int) -> int:
    """두 숫자를 곱한다."""
    print(f"\n[MULTIPLY] {a} * {b}")
    return a * b


# ---------------------------------
# LLM
# ---------------------------------

llm = ChatOpenAI(
    model="gpt-4.1-mini",
    api_key=os.getenv("OPENAI_API_KEY"),
    temperature=0
)


# ---------------------------------
# Agent
# ---------------------------------

agent = create_agent(
    model=llm,
    tools=[
        add,
        multiply
    ],
    system_prompt="""
    너는 계산 전문가이다.

    반드시 Tool을 사용하여 계산하라.
    """
)


# ---------------------------------
# 실행
# ---------------------------------

response = agent.invoke(
    {
        "messages": [
            {
                "role": "user",
                "content": "15와 20을 더한 후 2를 곱해줘"
            }
        ]
    }
)

print("\n====================")
print("결과")
print("====================")

print(response)

```

# Agent가 보는 정보

Tool 정의

```python
from langchain.tools import tool

@tool
def add(a: int, b: int) -> int:
    """두 숫자를 더한다."""
    print(f"\n[ADD] {a} + {b}")
    return a + b

```

LangChain은 이것을 내부적으로 다음과 같은 형태로 변환합니다.

```json
{
  "name": "add",
  "description": "두 숫자를 더한다.",
  "parameters": {
    "type": "object",
    "properties": {
      "a": {
        "type": "integer"
      },
      "b": {
        "type": "integer"
      }
    }
  }
}
```

이 정보가 GPT나 Gemini에 전달됩니다.

# 실제 Agent 로그 보기

>파일명 : step30.py

```python
from langchain.tools import tool
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI


# ----------------------------
# Tool
# ----------------------------

@tool
def add(a: int, b: int) -> int:
    """두 숫자를 더한다."""
    print(f"\n[TOOL] add({a}, {b})")
    return a + b


@tool
def multiply(a: int, b: int) -> int:
    """두 숫자를 곱한다."""
    print(f"\n[TOOL] multiply({a}, {b})")
    return a * b


# ----------------------------
# LLM
# ----------------------------

llm = ChatOpenAI(
    model="gpt-4.1-mini",
    temperature=0
)

# ----------------------------
# Agent
# ----------------------------

agent = create_agent(
    model=llm,
    tools=[add, multiply],
    system_prompt="""
    너는 계산 전문가이다.
    반드시 Tool을 사용하여 계산하라.
    """
)

# ----------------------------
# Stream 실행
# ----------------------------

for chunk in agent.stream(
    {
        "messages": [
            {
                "role": "user",
                "content": "15와 20을 더한 후 2를 곱해줘"
            }
        ]
    }
):
    print("\n====================")
    print(chunk)
```

```text
↓

Tool 호출 결정

↓

add(a=15,b=20)
```

즉 GPT는

```text
답변:
15+20=35입니다.
```

를 만든 것이 아닙니다.

대신

```json
{
  "name":"add",
  "args":{
      "a":15,
      "b":20
  }
}
```

를 생성한 것입니다.

# Tool 실제 실행

로그

```text
[TOOL] add(15, 20)
```

이 부분은

```python
@tool
def add(a:int,b:int):
    print(f"[TOOL] add({a},{b})")
    return a+b
```

가 실행된 것입니다.

실제로

```python
add(15,20)
```

가 호출된 순간입니다.

# 왜 Agent가 똑똑해 보이는가?

많은 사람들이

```text
Agent가 복잡한 알고리즘으로
숫자를 분석한다
```

고 생각합니다.

실제로는

```text
GPT가

1. Tool 선택

2. 매개변수 생성

3. 결과 해석

4. 다음 Tool 결정

을 반복 수행
```

하는 것입니다.

즉 이번 로그에서 가장 중요한 부분은

```python
tool_calls=[
    {
        'name':'add',
        'args':{
            'a':15,
            'b':20
        }
    }
]
```

와

```python
tool_calls=[
    {
        'name':'multiply',
        'args':{
            'a':35,
            'b':2
        }
    }
]
```

입니다.

이 두 줄이 바로 **"LLM이 자연어를 함수 호출(JSON)로 변환한 결과"** 입니다.

Agent를 이해했다는 것은 결국 **"LLM → Tool Call 생성 → Python 함수 실행 → 결과 반환 → LLM 재추론"** 구조를 이해했다는 의미인데, 지금 출력된 로그는 그 과정을 그대로 보여주고 있습니다.
