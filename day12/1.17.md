# LangChain 도구로 에이전트 만들기

`bind_tools()`의 목적은 **Agent를 만들지 않고, LLM이 어떤 Tool을 호출하려고 하는지 확인하는 것**입니다.

즉,

```text id="p1"
사용자 질문
 ↓
LLM
 ↓
Tool Call 생성
 ↓
끝
```

입니다.

실제 Tool 실행은 개발자가 직접 합니다.

---

# 예제 1. 가장 기본적인 bind_tools()

## Tool 정의

```python
from langchain.tools import tool

@tool
def add(a: int, b: int) -> int:
    """두 숫자를 더한다."""
    print(f"\n[TOOL] add({a}, {b})")
    return a + b


@tool
def multiply(a: int, b: int) -> int:
    """두 숫자를 곱한다."""
    print(f"\n[TOOL] multiply({a}, {b})")
    return a * b
```

---

## LLM 생성

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4.1-mini",
    temperature=0
)
```

---

## Tool 바인딩

```python
llm_with_tools = llm.bind_tools(
    [add, multiply]
)
```

---

## 질문

```python
response = llm_with_tools.invoke(
    "15와 20을 더해줘"
)
```

---

## 결과 확인

```python
print(response)
```

## 전체 코드

파일명 : step28.py

```python
import os
from langchain.tools import tool
from langchain.agents import create_agent

from langchain_openai import ChatOpenAI
import json

# ---------------------------------
# Tool
# ---------------------------------

@tool
def add(a: int, b: int) -> int:
    """두 숫자를 더한다."""
    print(f"\n[ADD] {a} + {b}")
    return a + b


@tool
def multiply(a: int, b: int) -> int:
    """두 숫자를 곱한다."""
    print(f"\n[MULTIPLY] {a} * {b}")
    return a * b


# ---------------------------------
# LLM
# ---------------------------------

llm = ChatOpenAI(
    model="gpt-4.1-mini",
    api_key=os.getenv("OPENAI_API_KEY"),
    temperature=0
)

# Tool 바인딩
llm_with_tools = llm.bind_tools(
    [add, multiply]
)

# 질문
response = llm_with_tools.invoke(
    "15와 20을 더해줘"
)

# 결과 확인
print(json.dumps(response.model_dump(), indent=4, ensure_ascii=False))

```

# 예제 2. Tool Call 보기 좋게 출력

```python
response = llm_with_tools.invoke(
    "15와 20을 더해줘"
)

for tool_call in response.tool_calls:

    print("Tool 이름:")
    print(tool_call["name"])

    print()

    print("매개변수:")
    print(tool_call["args"])
```

출력

```text
Tool 이름:
add

매개변수:
{'a': 15, 'b': 20}
```

# 예제 3. Tool 직접 실행하기

tool_call = response.tool_calls[0]

args = tool_call["args"]

print(tool_name)

{'a': 15, 'b': 20}
