# step12.py 예제

step12.py는 LangChain의 대화 기록 관리(Memory)를 서버 메모리에 저장하고, 이를 Gradio의 상태 관리(State)와 결합하여 실제 서비스 가능한 수준의 챗봇 구조를 완성하는 단계입니다.

이 파일을 학습하기 위한 기반 지식과 핵심 함수의 사용법을 정리해 드립니다.

---

## 1. 기반 지식 (Core Concepts)

### 1. 메서버 측 대화 저장소 (InMemoryChatMessageHistory)

* 이전 단계까지는 Gradio가 주는 history에 의존하거나 최근 N개만 잘라서 썼습니다.
* InMemoryChatMessageHistory는 LangChain에서 제공하는 객체로, 사용자의 질문(HumanMessage)과 AI의 답변(AIMessage)을 객체 형태로 차곡차곡 쌓아두는 전용 저장소입니다.
* 세션(Session) 관리: 사용자가 여러 명일 경우를 대비해 session_id를 키(Key)로 사용하여 사용자별로 각기 다른 대화 저장소를 배정합니다.

### 2. Gradio 상태 관리 (gr.State)

* 웹 브라우저를 새로고침하기 전까지 유지되는 사용자만의 비밀 변수입니다.
* 이 코드에서는 접속할 때마다 생성되는 고유한 uuid를 session_state에 저장하여, 서버가 "이 사용자가 누구의 대화 기록을 불러와야 하는지" 식별하는 용도로 씁니다.

### 3. 메시지 수동 주입 (Manual Formatting)

* LCEL(Chain)을 쓰지 않고 prompt.format_messages를 호출하여 [시스템 메시지 + 이전 대화 리스트 + 현재 질문]을 하나의 리스트로 합치는 과정을 직접 제어합니다.

```python
# ------------------------------------------
# Prompt 생성 및 이전 대화 결합
# ------------------------------------------
# 프롬프트 템플릿에 [이전 대화 목록]과 [현재 질문]을 주입하여 최종 메시지 번들 생성
messages = prompt.format_messages(
    chat_history=chat_history_obj.messages,
    question=message
)
```

## 2. 주요 함수 및 클래스 사용법

### 1. InMemoryChatMessageHistory

대화 내용을 메모리에 저장하는 클래스입니다.

* .messages: 저장된 모든 메시지 리스트를 가져옵니다.
* .add_user_message(text): 사용자의 말을 저장합니다.
* .add_ai_message(text): AI의 답변을 저장합니다.

### 2. get_session_history(session_id)

전역 변수인 store 딕셔너리를 관리하는 함수입니다.

* 해당 세션 ID가 처음 접속했다면 새로운 InMemoryChatMessageHistory 객체를 생성하고, 이미 있다면 기존 객체를 반환하여 대화가 이어지게 합니다.

### 3. prompt.format_messages(chat_history=..., question=...)

ChatPromptTemplate에 정의된 변수들에 실제 데이터를 채워 넣는 함수입니다.

* chat_history: MessagesPlaceholder 자리에 들어갈 메시지 객체 리스트입니다.
* question: {question} 자리에 들어갈 사용자의 현재 질문 문자열입니다.

### 4. uuid.uuid4()

* 절대 중복되지 않는 고유한 아이디(UUID)를 생성합니다. 세션 식별자로 활용됩니다.

## 3. 코드 로직 분석 (핵심 흐름)

chat 함수 내에서 일어나는 일들을 순서대로 이해하는 것이 가장 중요합니다.

1. 식별: session_id를 통해 이 사용자의 이전 대화 저장소(chat_history_obj)를 찾아옵니다.
2. 구성: 저장소에 있던 과거 메시지들과 지금 온 질문을 합쳐서 모델에게 보낼 전체 메시지(messages)를 만듭니다.
3. 기록(유저): 사용자가 방금 한 질문을 저장소에 add_user_message로 미리 넣어둡니다.
4. UI 준비: Gradio 화면에 사용자 질문을 먼저 띄우고, AI 답변이 들어갈 빈 칸을 만듭니다.
5. 실행 및 갱신: llm.stream으로 답변을 한 글자씩 받아 화면을 실시간 업데이트(yield)합니다.
6. 기록(AI): 답변이 모두 완료되면 완성된 전체 문장을 저장소에 add_ai_message로 저장합니다.
