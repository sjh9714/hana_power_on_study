# 8.3 실제 코드 분석

실제 프로젝트 코드

```python
from langchain_community.chat_message_histories import (
    ChatMessageHistory
)

store = {}

def get_session_history(
    session_id: str
):

    if session_id not in store:

        store[session_id] = (
            ChatMessageHistory()
        )

    return store[session_id]
```

# 수업 중 강조

```text
학생들이 가장 놀라는 부분이 있습니다.

LLM 자체는 기억력이 없습니다.

ChatGPT도 사실은

Memory를 따로 저장해서

다음 질문에 다시 전달하는 방식입니다.

즉,

기억하는 것이 아니라

다시 보여주는 것입니다.
```
