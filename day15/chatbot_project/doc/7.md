# 7.3 실제 코드 분석

실제 코드 형태

```python
from langchain_openai import (
    ChatOpenAI
)

from langchain_google_genai import (
    ChatGoogleGenerativeAI
)

from config.settings import (
    MODEL_CONFIG
)

def get_llm(
    selected_model
):

    if selected_model == "GPT":

        return ChatOpenAI(
            model=MODEL_CONFIG["GPT"]
        )

    elif selected_model == "Gemini":

        return ChatGoogleGenerativeAI(
            model=MODEL_CONFIG["Gemini"]
        )

    raise ValueError(
        "지원하지 않는 모델"
    )
```

# 수업 중 강조

```text
초급 개발자는 보통

ChatOpenAI()

를 직접 생성합니다.

하지만 실무에서는

Factory Pattern을 사용합니다.

왜냐하면 모델은 계속 바뀌고

GPT, Gemini, Claude 등을

유연하게 교체해야 하기 때문입니다.

llm_factory.py는

AI 프로젝트의 확장성을 결정하는

매우 중요한 파일입니다.
```
