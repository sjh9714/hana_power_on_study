# 9.1 LCEL이란?

LCEL

```text
LangChain Expression Language
```

---

LangChain 최신 표준 방식

---

예전 방식

```python
prompt_value = prompt.invoke(
    {
        "question":"안녕하세요"
    }
)

response = llm.invoke(
    prompt_value
)

result = parser.invoke(
    response
)
```

---

LCEL 방식

```python
chain = (
    prompt
    | llm
    | parser
)
```

---

장점

```text
짧다

가독성 좋다

재사용 가능

Streaming 가능
```

### 모범답안

