# 1.1 프로젝트 소개

chatbot_project는

```text
LangChain
+
OpenAI
+
Gemini
+
Gradio
+
Session Memory
```

를 사용하여 만든 챗봇 프로젝트이다.

---

초급 개발자가 흔히 하는 오해

```text
app.py가 가장 중요하다.
```

❌

실제로는

```text
chat_service.py
chat_chain.py
```

가 핵심이다.

# 수업 중 강조

ㄴ학생들이 프로젝트를 처음 보면

```text
어디부터 봐야 하나요?
```

라고 묻는다.

이때

```text
app.py
```

부터 보지 말고

```text
chat_service.py
```

부터 보라고 설명한다.

왜냐하면 실제 요청 흐름은

```text
UI
↓
Service
↓
Chain
```

순서이기 때문이다.
