학생들은 드디어

RAG를 만들 준비가 완료된 것입니다.

많은 사람들이

RAG = Vector DB

라고 생각하지만

실제로는

Document
→ Chunk
→ Embedding
→ VectorDB
→ Retriever
→ Prompt
→ LLM

전체 과정을 이해해야 합니다.

이 장이 바로

retrievers_refactoring 프로젝트와

agri_rag_chatbot 프로젝트를 연결하는

가장 중요한 장입니다.
