# 6.4 실제 코드 분석

예시

```python
from langchain_chroma import (
    Chroma
)

def create_vectorstore(
    chunks,
    embeddings
):

    vectorstore = (
        Chroma.from_documents(
            documents=chunks,
            embedding=embeddings,
            persist_directory=
                "./chroma_db"
        )
    )

    return vectorstore
```

# 수업 중 강조

```text
많은 학생들은

RAG의 핵심이 GPT라고 생각합니다.

하지만 실제 RAG 프로젝트에서는

GPT보다

ChromaDB + Retriever

성능이 더 중요합니다.

왜냐하면

잘못 검색된 문서를

GPT가 읽으면

답변도 잘못되기 때문입니다.

즉,

RAG 품질은

검색 품질이 결정합니다.
```
