# 3.9 Document 전처리 함수

실무 예제

```python
import re
import unicodedata

def clean_text(
    text
):

    text = unicodedata.normalize(
        "NFC",
        text
    )

    text = "".join(
        ch
        for ch in text
        if not unicodedata.category(
            ch
        ).startswith("C")
        or ch in [
            "\n",
            "\t",
            "\r"
        ]
    )

    text = re.sub(
        r"\s+",
        " ",
        text
    )

    return text.strip()
```

### Q1

전처리를 안 해도 동작하나요?

A.

동작은 하지만 검색 품질이 크게 떨어질 수 있습니다.

### Q2

개행을 모두 제거하면 안 되나요?

A.

문맥 구조가 깨질 수 있으므로 주의해야 합니다.

---

### Q3

전처리가 Embedding보다 중요한가요?

A.

좋은 Embedding도 나쁜 입력 데이터는 보완할 수 없습니다.
