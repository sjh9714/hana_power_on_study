# 수업 중 강조

```text
학생들은 Embedding을 어려워합니다.

하지만 실제로는

문장을 숫자로 바꾸는 과정

이라고 생각하면 됩니다.

RAG의 핵심은

LLM보다

Retriever입니다.

Retriever의 핵심은

Embedding입니다.

따라서

Embedding을 이해하면

RAG의 절반을 이해한 것입니다.
```

# 예상 질문

### Q1

Embedding 모델과 LLM은 같은 건가요?

A.

아닙니다.

Embedding은 벡터 생성,
LLM은 답변 생성입니다.

---

### Q2

왜 Query와 Document 함수를 나누나요?

A.

검색 최적화를 위해 분리된 경우가 많습니다.

---

### Q3

Embedding 모델을 바꾸면 성능이 좋아지나요?

A.

경우에 따라 크게 좋아질 수 있습니다.

특히 한국어 문서는 모델 선택이 중요합니다.

## 주관식

### 3

embed_query()와 embed_documents()의 차이를 설명하시오.

### 모범답안

```text
embed_query()는 사용자의 질문을 벡터로 변환하기 위해 사용하며,

embed_documents()는 문서를 벡터화하여 Vector DB에 저장하기 위해 사용한다.

RAG에서는 문서는 embed_documents(),
질문은 embed_query()를 사용하여 같은 의미 공간에서 비교한다.
```
