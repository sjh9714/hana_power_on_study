# 라우팅(Routing) 종류

라우팅(Routing)은 AI 시스템, RAG, Agent, LangChain, LangGraph에서 매우 중요한 개념이며 목적에 따라 여러 종류로 나눌 수 있습니다.

# 1. Query Routing (질문 라우팅)

가장 기본적인 라우팅입니다.

사용자 질문을 분석하여 처리 경로를 선택합니다.

```text
질문
 │
 ▼
Router
 │
 ├── GPT
 ├── RAG
 ├── Web Search
 └── Database
```

예)

```text
GPT란?
```

↓

```text
GPT
```

---

```text
밀 재배관리 시스템
```

↓

```text
RAG
```

예제 코드는 routing/step1.py을 참조하세요

# 3. Hybrid Search Routing

검색을 수행할지 여부를 결정합니다.

```text
질문
 │
 ▼
Search Router
 │
 ├── 검색 필요
 │      │
 │      ▼
 │     RAG
 │
 └── 검색 불필요
        │
        ▼
       GPT
```

예)

```text

```


```text

```

# 9. Multi-Agent Routing

Agent가 다시 다른 Agent에게 작업을 위임합니다.

```text
사용자
 │
 ▼
Supervisor Agent
 │
 ├── 농업 Agent
 ├── 기상 Agent
 ├── 데이터분석 Agent
 └── 보고서 Agent
```

예)

```text

```

↓

```text

농업 Agent

분석 Agent

보고서 Agent
```

# 10. Semantic Routing

키워드가 아니라 의미 기반으로 라우팅합니다.

예)

```text
밀 재배관리 방법
```

---

```text
Wheat cultivation management
```

---

```text
작물 생육 관리
```

세 질문 모두

```text
농업 경로
```

로 이동합니다.

보통 임베딩(Embedding)을 사용합니다.

```text
질문
 │
 ▼
Embedding
 │
 ▼
유사도 계산
 │
 ▼
적절한 경로 선택
```

# 11. Conditional Routing

조건에 따라 분기합니다.

LangGraph에서 매우 많이 사용됩니다.

```text
질문
 │
 ▼
조건 검사
 │
 ├── Yes
 │     │
 │     ▼
 │    RAG
 │
 └── No
       │
       ▼
      GPT
```

---

```text

      ▼
Hybrid Search Router
      │
      ├── GPT
      │
      └── RAG
              │
              ▼
      Retriever Router
              │
              ├── 밀 재배
              ├── 토양
              ├── 병충해
              └── 기상
                      │
                      ▼
               Prompt Router
                      │
                      ▼
                 Model Router
                      │
                      ▼
                    답변
```
