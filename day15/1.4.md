# RAG & Retriever 관련 기능 refactoring

지금은 **기능 추가보다 구조 개선(Refactoring)** 이 가장 중요한 시점입니다.

현재 코드는 다음과 같은 문제가 있습니다.

```text id="yv5m1s"
step03.py

- Embedding
- Chroma
- Retriever
- Prompt
- Router
- RAG Chain
- GPT Chain
- 실행 코드

전부 한 파일
```

이 상태에서 새로운 기능을 추가하면 코드가 점점 복잡해 집니다. 이를 해결하기 위해서 한개의 파일로 된 코드를 논리적인 기능별로 분리하겠습니다

# 6 단계

utils/document_utils.py

```python id="kpngod"
def format_docs_with_pages(docs):

    context = "\n\n".join(
        doc.page_content
        for doc in docs
    )

    pages = sorted(
        set(
            doc.metadata.get("page")
            for doc in docs
            if doc.metadata.get("page")
            is not None
        )
    )

    page_text = ", ".join(
        map(str, pages)
    )

    return {
        "context": context,
        "page_text": page_text
    }
```

# 10 단계

chains/rag_chain.py

```python id="0d1hpr"
from langchain_core.runnables import (
    RunnableLambda,
    RunnablePassthrough
)

from retrievers.retriever import (
    get_retriever
)

from prompts.rag_prompt import (
    rag_prompt
)

from llms.llm import get_llm

from utils.document_utils import (
    format_docs_with_pages
)

from langchain_core.output_parsers import (
    StrOutputParser
)

retriever = get_retriever()

llm = get_llm()

parser = StrOutputParser()

rag_chain = (
    {
        "docs": retriever,
        "query": RunnablePassthrough()
    }
    | RunnableLambda(
        lambda x: {
            **format_docs_with_pages(
                x["docs"]
            ),
            "query": x["query"]
        }
    )
    | rag_prompt
    | llm
    | parser
)
```

# 12 단계

chains/router_chain.py

```python id="i03m1o"
from prompts.router_prompt import (
    router_prompt
)

from chains.rag_chain import (
    rag_chain
)

from chains.general_chain import (
    general_chain
)

from llms.llm import get_llm

from langchain_core.output_parsers import (
    StrOutputParser
)

llm = get_llm()

parser = StrOutputParser()

router_llm_chain = (
    router_prompt
    | llm
    | parser
)

def ask(query):

    category = (
        router_llm_chain.invoke(
            {"query": query}
        )
        .strip()
        .lower()
    )

    if category == "rag":

        return rag_chain.invoke(
            query
        )

    return general_chain.invoke(
        query
    )
```
