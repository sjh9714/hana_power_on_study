# Public Data Policy

이 문서는 `hana_power_on_study` 저장소를 포트폴리오로 공개할 때의 데이터와 자료 공개 기준을 정리합니다.

## 기본 원칙

- 직접 작성한 코드와 회고는 공개할 수 있습니다.
- 교육 자료 원문, 내부 제공 데이터, 개인정보, 금융 거래 원본 데이터는 공개하지 않습니다.
- API key, token, secret, 인증서, 계정 정보는 절대 커밋하지 않습니다.
- 실제 금융 조언처럼 보이는 단정적 문장은 피하고, 학습/실습 목적임을 분명히 합니다.

## 공개해도 좋은 것

- 직접 작성한 Python 코드
- 직접 작성한 README와 회고 문서
- 공개 가능한 샘플 데이터
- 직접 만든 다이어그램
- 에러 해결 과정
- 실행 방법과 폴더 구조
- 결과 화면이나 요약 통계

## 주의가 필요한 것

- 교육 과정에서 제공된 원본 슬라이드 또는 문서
- 출처와 라이선스가 불명확한 PDF
- 실제 개인정보가 포함될 수 있는 데이터
- 실제 거래 내역 또는 금융 데이터 원본
- Chroma DB 같은 임베딩 산출물
- 모델 응답 로그와 대화 기록
- `.zip`, `.z01`, `.z02` 같은 대형 압축 파일

## 현재 저장소 상태

공개 저장소 안전화를 위해 다음 종류의 파일은 현재 트래킹과 Git 히스토리에서 제거했습니다.

- `data/credit_card_transactions.zip`
- `data/credit_card_transactions.z01`
- `data/credit_card_transactions.z02`
- `day13`, `day14`, `day15`, `day16` 하위 Chroma DB 산출물
- `day13`, `day14` 하위 PDF 원본
- `day13/output/` OCR/전처리 산출물
- `day15`, `day16` 하위 zip 산출물

재현 설명은 [`sample_data`](../sample_data)의 synthetic 데이터와 [`scripts`](../scripts)의 생성 스크립트를 기준으로 합니다.

## 다시 커밋하지 않기 위한 기준

아래 항목은 `.gitignore`로 관리하며, 필요할 경우 로컬에서만 보관합니다.

1. 대형 압축 파일과 원본 데이터
2. PDF 원본과 교육 자료 원문
3. OCR/output 산출물
4. Chroma/vector DB 산출물
5. `.env`, API key, token, secret
6. 모델 파일, 캐시, 로컬 DB

## 공개 재현 방식

1. 실제 데이터가 필요한 설명은 synthetic 샘플 데이터로 대체합니다.
2. 샘플 데이터는 `python3 scripts/create_sample_credit_data.py`로 재생성합니다.
3. RAG 실습은 공개 가능한 문서를 로컬에서 준비한 뒤 인덱스를 재생성합니다.
4. 원본 교육 자료나 내부 데이터는 링크하거나 요약하지 않습니다.

## README에 남길 공개 문구

```text
이 저장소는 교육 과정에서 작성한 개인 학습 기록입니다.
공개 저장소에는 실제 거래 원본, 교육 자료 원문, 벡터 DB 산출물을 포함하지 않으며,
실제 금융 상품 추천 또는 운영 서비스 구현체가 아닙니다.
```
